\caption{\sys architecture on a live CADETS-style stream, with the two
queries of Example~\ref{ex:queries} drawn in their colors. The
\textcolor{wins}{insert path} \textcolor{wins}{\ding{182}} computes the
slot arithmetically, \textcolor{wins}{\ding{183}} claims an arrival run
with one atomic, and \textcolor{wins}{\ding{184}} publishes payload-first,
timestamp-last, so \textcolor{qwin}{\textbf{Q1}} walks only the timeline
(interior blocks copied without comparisons) and
\textcolor{qnbr}{\textbf{Q2}} binary-searches the sorted prefix and
touches the arena only for edges that pass the window test. No structure
here is maintained per write except the append chains themselves.}
